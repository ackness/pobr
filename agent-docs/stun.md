# 眩晕机制 (Stun)

眩晕是一种控制效果，当一次击中造成的伤害超过目标的**眩晕阈值 (Stun Threshold)** 时触发[^mobalytics-damage-order]。

## 基本机制

### 眩晕阈值

- 默认基于目标的**最大生命 (Maximum Life)**
- 较强的怪物有调整的眩晕阈值，使它们更难被眩晕
- 某些怪物可能完全免疫眩晕

### 触发条件

当一次击中的伤害超过目标的眩晕阈值时，眩晕被施加。

### 眩晕持续时间

眩晕持续时间基于：
- 造成的伤害量
- 目标的眩晕阈值
- 某些修饰词可以缩短或延长眩晕持续时间

## 重眩晕 (Heavy Stun)

### 重眩晕积累

- 普通眩晕伤害积累**眩晕**
- **重眩晕 (Heavy Stun)** 属于**姿态 (Poise)** 相关 debuff，与冻结、电击、钉刺 (Pin) 同属一类[^pob2-deepwiki-stun]
- 重眩晕积累可由**所有伤害类型**（物理、火焰、冰霜、闪电、混沌）贡献，但物理近战伤害通常有额外加成[^pob2-deepwiki-stun]
- 不同怪物有不同的重眩晕阈值和持续时间

### 重眩晕效果

- 比普通眩晕持续时间**更长**
- 不同怪物的重眩晕阈值和持续时间各不相同
- 某些怪物可能有特殊重眩晕机制

### 玩家与重眩晕

**玩家不能被重眩晕。**

> **0.5.0 更新**：格挡、招架和共振盾不再延迟重眩晕积累的预期衰减时间[^maxroll-050-patchnotes]。

## 玩家对重眩晕的加成

玩家物理和近战击中伤害对重眩晕积累通常有额外加成（如 **50% More**），但所有伤害类型均可贡献积累[^pob2-deepwiki-stun]。

这意味着：
- 物理近战构建更容易使怪物进入重眩晕状态
- 法术和远程攻击同样可以积累重眩晕，但效率通常低于物理近战

## 眩晕免疫与抵抗

### 眩晕免疫

某些情况可能提供眩晕免疫：
- 特定技能或增益效果
- 某些升华职业特性
- 某些传奇物品
- 某些药瓶效果

### 减少被眩晕几率

可以通过以下方式降低被眩晕的风险：
- 增加生命（提高眩晕阈值）
- 增加能量护盾（伤害先由 ES 承受）
- 某些被动技能节点
- 某些装备修饰词

## 眩晕与格挡

**重要**：即使击中**被格挡**，仍然可以造成眩晕。这是因为：
- 格挡只防止伤害数值
- 但击中仍然发生
- 如果原始伤害超过眩晕阈值，眩晕仍然被施加

## 眩晕与闪避

如果击中**被闪避**，则不会造成眩晕，因为击中被完全丢弃。

## 眩晕与持续伤害

持续伤害（如流血、点燃、毒）不会直接造成眩晕，因为：
- 眩晕只在**击中 (Hit)** 时检查
- 持续伤害不是击中

## 防御计算顺序中的眩晕

```
步骤 6: 眩晕 (Stun)
- 在减伤和伤害承受修饰词之后
- 在格挡之前
```

这意味着：
- 伤害先被减免
- 然后应用伤害承受修饰词
- 然后检查是否超过眩晕阈值
- 最后检查格挡

## 眩晕与构建策略

### 眩晕规避构建

- 堆叠高生命以提高眩晕阈值
- 使用能量护盾作为缓冲
- 获取眩晕免疫或几率避免眩晕
- 使用增加眩晕阈值的被动技能

### 眩晕施加构建

- 物理近战构建有 50% More 重眩晕积累加成
- 堆叠高单次击中伤害
- 某些技能或装备可能增加眩晕持续时间或效果

## 相关机制

- **眩晕阈值 (Stun Threshold)**：基于最大生命
- **格挡 (Block)**：不能防止眩晕
- **闪避 (Evasion)**：可以完全避免眩晕
- **生命 (Life)**：影响眩晕阈值
- **能量护盾 (Energy Shield)**：作为伤害缓冲

# 前端交互与文案检查

范围：本地前端的构建、装备、技能、天赋树、计算、战斗配置、提升与流派参考；保留现有深色视觉风格与计算模型，不涉及版本发布。

## 首轮交互与文案改进

现有页面按角色规划任务分区，装备槽位、主技能选择和常驻数据栏有助于理解计算对象，无需整体重做。更值得优先改善的是操作后果、反馈、输入过程和跨页入口。

| 部分 | 检查结论 | 本次改进 |
| --- | --- | --- |
| 全局外壳 | 深色层级与金色强调一致；Beta 横幅把 API 实现细节暴露给普通用户。 | 横幅改为说明计算覆盖范围；扩大触屏主要控件尺寸，完善减少动态效果偏好。 |
| 构建与导入 | 导入失败仍切页，容易被理解成成功；职业选择实际会清空构筑；窄屏导入入口落在笔记后。 | 导入成功才进入装备页，失败保留输入与构筑；文件读取失败显示提示；构建和天赋树两个职业入口都支持取消清空；导入卡片移到笔记前。 |
| 分享与备份 | 旧分享码不会随编辑失效；“Code”“JSON”不直接表达用途；复制失败没有提示。 | 编辑后隐藏旧码并提示重新生成；使用“生成分享码”“下载备份”“从文件导入”等文案；说明备份用途与导入替换范围；复制失败提供可选中的原始文本。 |
| 装备 | 槽位选择、编辑、保存、比较的流程合理；通用下拉框和已有备注的键盘操作不完整。 | 装备保存动作明确为保存并重算；备注可通过键盘重新编辑；装备、符文、珠宝共用的下拉框获得统一键盘与焦点行为。 |
| 技能 | 搜索和属性筛选有助于选择宝石；筛选按钮的 Enter 会被父层误解成“添加宝石”，关闭列表后方向键无法重新打开。 | 分离输入框和筛选按钮的键盘行为；补齐活动选项、列表关联和筛选选中状态；离开控件关闭列表，Escape 关闭后可用方向键重开。 |
| 天赋树 | 搜索定位、路径加点和热力图支持不同任务，现阶段保留。职业选择同样存在清空风险。 | 与构建页使用相同清空提示；珠宝选择复用改进后的下拉框。 |
| 计算 | 数据分类和来源展开适合分析；说明存在 base/inc 等实现术语，搜索无结果没有出口。 | 使用基础值、加成和词条来源说明；增加无结果提示与清除搜索操作；解释来源贡献计算的用途和耗时。 |
| 战斗配置 | 数字每次输入即重算会打断编辑；重置按钮含义不明确；导入值可能只在界面恢复，没有恢复到计算请求。 | 数字和文本在失焦或 Enter 后提交；标签可激活对应控件；还原导入值或默认值，界面与请求一致；仅对实际修改显示还原；增加搜索空态、加载状态和失败重试。 |
| 提升 | 换装试算、词条评分、官方市集搜索各有用途，现有说明已经区分参考收益与商品收益。 | 货币、服务器、赛季等下拉框统一支持方向键、Home/End、Enter、Escape 和离开控件关闭；长选项允许换行。 |
| 流派参考 | 已明确历史样本与实时天梯的区别；三个按钮同名但跳到不同页面。 | 分别改为规划辅助宝石、比较装备提升、规划天赋路径，并用箭头提示跳转。 |

中英文与繁简中文的本次新增及修改文案同步维护；游戏技能名与词条翻译仍以现有数据包为准。

## 逐项操作与页面动线复查

本轮使用实际导入的 Monk / Invoker 构筑、空白角色和合成边界数据进行浏览器操作，并查看桌面与窄屏截图。页面顺序围绕“确认当前对象与目标 → 编辑或选择候选 → 查看变化 → 应用”调整。

| 页面 | 布局与操作调整 |
| --- | --- |
| 构筑 | 代码导入与文件导入归入同一卡片；分享和备份置于笔记前。卡片按内容高度展示；导航中的“构筑”与页内用语统一。 |
| 装备 | 缩短窄屏槽位卡片；点选后将详情与焦点移入视野。详情内可切换全部 15 个位置，无需反复返回长槽位列表。 |
| 技能 | 增加直达当前主技能编辑的入口；保留技能组原始编号。常见手机宽度下，宝石名称与等级、品质保持同一行；更窄屏仍允许换行。 |
| 天赋 | 宽屏画布与属性、珠宝和规划工具并排，滚动规划结果时仍可查看树。窄屏先显示画布，提供“属性与规划”定位入口；选择珠宝时显示其编辑器。 |
| 计算 | 提供技能 DPS、来源归因的定位入口；展开数值来源后使用整行宽度，减轻表格拥挤。 |
| 配置 | 敌人档位、搜索和“仅显示已配置”集中在固定工具栏；筛选可与搜索组合，保留导入的 false 值，空结果可恢复全部目录。 |
| 提升 | 先确认目标、主技能、武器组与约束，再进入换装或规划；市集预算、服务器和赛季靠近市集分析。窄屏规划入口并排展示，详细评分说明按需展开。 |
| 构筑参考 | 当前构筑之后直接展示实时查找和粘贴参考入口，随后是历史样本；后续规划卡片移至对照之后，详情提供返回样本的入口。 |

实际操作发现并修复的功能问题：

- 装备和珠宝草稿曾因切页或切位置丢失。现在按位置保留本次打开期间的草稿，武器草稿区分武器组；保存才参与计算、分享和备份，取消明确丢弃。整份导入、切换配置组或新建角色会清除草稿；关闭页面时未应用草稿有浏览器提示。
- 底部的武器绑定和宝石选择菜单曾被滚动容器裁切。通用菜单根据上下可用空间选择展开方向，并限制高度。
- “取消分配珠宝插槽”曾只移除珠宝，没有移除天赋点。节点及其珠宝现在一次更新，实际构筑的 #7960 插槽已验证。
- 主技能或构筑变更后，来源归因曾继续显示旧结果。现在旧结果立即失效并提示重算，异步旧请求也不能覆盖新结果；逐技能 DPS 同样绑定当前构筑状态。
- 装备库的药剂曾写入普通装备数组；不兼容位置也可强行装备。现在药剂和护符走对应位置，并限制装备与比较到兼容位置；比较结果随构筑及位置变更失效。
- 导入无笔记构筑或新建角色曾保留上一个角色的笔记。现在空笔记也会替换旧笔记，笔记及草稿纳入未保存状态判断。
- 配置目录同一变量重复出现，前端展示了两种名称和控件。前端按后端“最后一个定义生效”的规则去重，避免用户配置同一变量的两个入口。

## 后续优化方向

以下属于需要单独设计或进一步验证的工作，本次未实现：

1. **战斗配置的常用项入口。** 本轮增加了“仅显示已配置”，但已配置不等于对当前技能生效。按技能筛选常用条件和补齐人工核对后的翻译仍需进一步设计。
2. **移动端天赋树的独立操作设计。** SVG 画布适合鼠标，触屏加点、缩放、节点说明和键盘节点导航需要专门设计与真实设备验证，不能仅凭页面没有横向溢出判定完成。
3. **优化结果的跨页保留。** 可让用户在装备、技能、天赋之间来回查看时保留规划进度，同时明确标记构筑变更后的过期结果；需要先确定结果与构筑版本的对应规则。
4. **资源加载拆分。** 当前生产构建提示主 JS chunk 超过 500 kB。后续可测量首屏与切页耗时，再决定是否按功能懒加载；本次未为消除提示而调整依赖或构建配置。

## 验证范围与记录

交互回归见 `web/e2e/usability.spec.ts`；既有构筑往返、存档、手工建构与 WeGame 导入流程用于检查兼容性。响应式检查覆盖 `320 / 768 / 1024 / 1440` 宽度的全部八个主页面，另做简体中文浏览器走查。

首轮验证结果：生产构建（包含 TypeScript 类型检查）通过；导入、主技能与笔记颜色解析的 11 项单元测试通过；上述 7 个 E2E 文件共 26 项用例均已通过，失败修复后按影响范围复跑。复用未受后续修改影响的通过结果。

本次验证限于前端与既有 WASM 的交互，不等同于重新验证所有计算机制、真实市集交易、所有浏览器或真实触屏设备。


本轮复查记录：

- Ego 中实际查看 15 个装备位置、13 个技能组，操作保存/取消、装备库、符文插槽、宝石等级与品质、三个武器绑定、辅助筛选与方案应用、天赋搜索/热力图/规划/珠宝及计算来源。一次辅助规划完成 370 次重算并实际应用候选。
- Ego 重启后原测试空间 24 已丢失，恢复创建问题待用户答复；此后的验证通过仓库既有 Playwright 浏览器流程完成，未接管用户原有空间。
- `config-controls.spec.ts` 遍历 7 个分区的全部 564 个唯一配置控件，执行 669 次选项切换，以及重算、持久化和还原检查。该检查证明控件通路可用，不证明每种条件的游戏机制均已被计算引擎实现。
- `functional-review.spec.ts` 记录草稿、插槽原子更新、菜单边界、空笔记替换、归因失效、药剂库装备等回归；`layout-workflow.spec.ts` 检查桌面与手机详情定位、全部位置切换、配置筛选与跨区定位。
- `visual.spec.ts` 检查全部八页在 320 / 768 / 1024 / 1440 宽度的横向边界，并为实际构筑生成 390 / 1440 宽度截图；`build-guidance.spec.ts` 另覆盖四种宽度的中文参考详情。截图输出到忽略目录 `web/e2e/screenshots/`，不随源码提交。

本轮最终结果：生产构建及 TypeScript 检查通过；导入、主技能、笔记颜色与注释的 14 项单元测试通过；相关 12 个 E2E 文件累计 55 项用例通过。首次批量检查中一项搜索空态按钮名称不匹配，已保留普通搜索的“清除搜索”，仅在配置筛选启用时使用“显示全部选项”；修复后相关用例通过。最终装备定位调整后再跑受影响的 26 项浏览器用例，全部通过；其他未受影响的通过结果复用。生产构建仍提示主 JS chunk 超过 500 kB，未改变打包策略。未执行发布、推送或版本号更新。

Review 后续修复：

- 在 390 × 500 窗口中，装备菜单自身的滚动会触发重新测量高度，导致滚动位置回跳、末尾选项不可达。定位逻辑现在忽略菜单及内部列表的滚动，仍响应页面滚动和窗口变化；实测滚轮滚至末尾并选择最后一项，另覆盖宝石内部列表。
- 取消珠宝插槽时，同步清理级联撤销节点的属性选择，保留仍已分配节点的选择。回归覆盖 Warrior 连通路径中的 #2491 插槽及下游 #51561 属性节点，并验证重新分配路径不会恢复旧属性选择。
- 修复前新增测试复现了菜单距底部仍差 63 px、已撤销属性选择残留的问题。修复后生产构建（含类型检查）、天赋图与武器组的 10 项单元测试，以及功能复查、页面动线、可用性、提升规划的 26 项浏览器测试全部通过。仅本地修复，未推送、发布或更新版本号。

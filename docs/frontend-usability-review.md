# 前端交互与文案检查

范围：本地前端的构建、装备、技能、天赋树、计算、战斗配置、提升与流派参考；保留现有深色视觉风格与计算模型，不涉及版本发布。

## 判断与已落实的改进

现有页面按角色规划任务分区，装备槽位、主技能选择和常驻数据栏有助于理解计算对象，无需整体重做。更值得优先改善的是操作后果、反馈、输入过程和跨页入口。

| 部分 | 检查结论 | 本次改进 |
| --- | --- | --- |
| 全局外壳 | 深色层级与金色强调一致；Beta 横幅把 API 实现细节暴露给普通用户。 | 横幅改为说明计算覆盖范围；扩大触屏主要控件尺寸，完善减少动态效果偏好。 |
| 构建与导入 | 导入失败仍切页，容易被理解成成功；职业选择实际会清空构筑；窄屏导入入口落在笔记后。 | 导入成功才进入装备页，失败保留输入与构筑；文件读取失败显示提示；构建和天赋树两个职业入口都支持取消清空；导入卡片移到笔记前。 |
| 分享与备份 | 旧分享码不会随编辑失效；“Code”“JSON”不直接表达用途；复制失败没有提示。 | 编辑后隐藏旧码并提示重新生成；使用“生成分享码”“下载备份”“从文件导入”等文案；说明备份用途与导入替换范围；复制失败提供可选中的原始文本。 |
| 装备 | 槽位选择、编辑、保存、比较的流程合理；通用下拉框和已有备注的键盘操作不完整。 | 装备保存动作明确为保存并重算；备注可通过键盘重新编辑；装备、符文、珠宝共用的下拉框获得统一键盘与焦点行为。 |
| 技能 | 搜索和属性筛选有助于选择宝石；筛选按钮的 Enter 会被父层误解成“添加宝石”，关闭列表后方向键无法重新打开。 | 分离输入框和筛选按钮的键盘行为；补齐活动选项、列表关联和筛选选中状态；离开控件关闭列表，Escape 关闭后可用方向键重开。 |
| 天赋树 | 搜索定位、路径加点和热力图支持不同任务，现阶段保留。职业选择同样存在清空风险。 | 与构建页使用相同清空提示；珠宝选择复用改进后的下拉框。 |
| 计算 | 数据分类和来源展开适合分析；说明存在 base/inc 等实现术语，搜索无结果没有出口。 | 使用基础值、加成和词条来源说明；增加无结果提示与清除搜索操作；解释来源贡献计算的用途和耗时。 |
| 战斗配置 | 数字每次输入即重算会打断编辑；重置按钮含义不明确；导入值可能只在界面恢复，没有恢复到计算请求。 | 数字和文本在失焦或 Enter 后提交；标签可激活对应控件；还原导入值或默认值，界面与请求一致；仅对实际修改显示还原；增加搜索空态、加载状态和失败重试。 |
| 提升 | 换装试算、词条评分、官方市集搜索各有用途，现有说明已经区分参考收益与商品收益。 | 货币、服务器、赛季等下拉框统一支持方向键、Home/End、Enter、Escape 和离开控件关闭；长选项允许换行。 |
| 流派参考 | 已明确历史样本与实时天梯的区别；三个按钮同名但跳到不同页面。 | 分别改为规划辅助宝石、比较装备提升、规划天赋路径，并用箭头提示跳转。 |

中英文与繁简中文的本次新增及修改文案同步维护；游戏技能名与词条翻译仍以现有数据包为准。

## 后续优化方向

以下属于需要单独设计或进一步验证的工作，本次未实现：

1. **装备与珠宝编辑草稿保护。** 当前局部编辑器在切槽位或切页时会卸载；可引入与槽位关联的草稿及明确的保存/放弃状态，先定义导入、换配置组时如何处理草稿。
2. **战斗配置的常用项入口。** 当前目录包含大量条件，中文标签仍有部分英文回退。可按当前技能展示常用条件、突出正在生效的修改，并继续补齐人工核对后的翻译；高级目录仍应可访问。
3. **移动端天赋树的独立操作设计。** SVG 画布适合鼠标，触屏加点、缩放、节点说明和键盘节点导航需要专门设计与真实设备验证，不能仅凭页面没有横向溢出判定完成。
4. **优化结果的跨页保留。** 可让用户在装备、技能、天赋之间来回查看时保留规划进度，同时明确标记构筑变更后的过期结果；需要先确定结果与构筑版本的对应规则。
5. **资源加载拆分。** 当前生产构建提示主 JS chunk 超过 500 kB。后续可测量首屏与切页耗时，再决定是否按功能懒加载；本次未为消除提示而调整依赖或构建配置。

## 验证范围

交互回归见 `web/e2e/usability.spec.ts`；既有构筑往返、存档、手工建构与 WeGame 导入流程用于检查兼容性。响应式检查覆盖 `320 / 768 / 1024 / 1440` 宽度的全部八个主页面，另做简体中文浏览器走查。

验证结果：生产构建（包含 TypeScript 类型检查）通过；导入、主技能与笔记颜色解析的 11 项单元测试通过；上述 7 个 E2E 文件共 26 项用例均已通过，失败修复后按影响范围复跑。复用未受后续修改影响的通过结果。

本次验证限于前端与既有 WASM 的交互，不等同于重新验证所有计算机制、真实市集交易、所有浏览器或真实触屏设备。

市集装备，一键复制比较

在国服或国际服 PoE2 官方市集，每件已加载的商品旁添加「复制到 PoBR」。复制完整物品文本，再回到「提升」页粘贴，即可比较当前角色换装后的变化。

安装复制脚本 · v0.1.0

  1. 先安装 Tampermonkey（油猴），再点击上方按钮并确认安装。若只看到源码，在油猴中新建脚本，粘贴完整源码并保存。
  2. 刷新已经登录的市集搜索页，在目标商品旁点击「复制到 PoBR」。
  3. 返回 PoBR「提升」页粘贴。确认 DPS、EHP、抗性和未支持词条后，再决定是否购买。

复制哪些内容

包含基底、稀有度、需求等级、品质、已显示的防御值、隐式、符文、附魔、工艺及破裂词缀。魔法物品使用可识别的基底名，完整原名保存在 Note 中；空插槽不会被当成已镶嵌符文。

未知效果会保留为待复核信息。物品能够复制不代表全部效果已被计算；主动技能石和血脉宝石仍需使用对应的技能提升流程。

读取范围

只在你点击时，通过当前市集的同源接口读取这一件商品。只复制物品数据，不复制价格、卖家、账号、密语或 Cookie，也不会自动联系卖家或购买。登录验证和限流需要在市集页面处理，脚本不会自动重试。

若剪贴板写入失败，会显示可手动选中复制的文本窗口。脚本支持无限滚动加载的商品；市集改版后可能需要更新脚本。

English: Install the userscript in Tampermonkey, reload an official PoE2 market search, click “Copy for PoBR”, then paste into PoBR → Upgrades. The script reads only the clicked listing and copies item text, without seller details or automatic purchases.
